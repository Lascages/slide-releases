# Slide — versions

Ce dépôt ne contient que les **versions publiées** de Slide (fichiers `.dmg` dans « Releases ») et le fichier `appcast.xml` lu par la mise à jour automatique. Le code source est privé.

Installation : téléchargez le dernier `Slide-x.y.z.dmg` dans [Releases](../../releases/latest), glissez Slide dans Applications. Ensuite l'app se met à jour toute seule (Réglages > Mises à jour).
